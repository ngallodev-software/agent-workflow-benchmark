# Fast benchmark operating target

`priority-picker-fast-v1` is the short paired benchmark. It preserves the same two-arm isolation, headless execution, optional live application review, six-dimension 100-point machine score, blinded human assessment, and evidence lifecycle as the full suite.

The model receives one bounded repair-and-verify phase with a hard timeout of **150 seconds**. The fixture is intentionally near-complete, so normal successful runs should finish the model work in under three minutes per paired run; visual capture, scoring, and human review occur after the model phase and are measured separately.
